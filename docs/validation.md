## 自动化软件测试

`python Lib/stm_sdram/tests/run_tests.py` 编译实际驱动源码，用工程中的真实 HAL 类型和常量，
在 Unicorn Cortex-M 模拟器中执行。只有 HAL 外设调用被 mock，存储访问和参数检查执行实际 ARM 指令。
测试失败时脚本非零退出并报告 C 测试行号；每个场景有指令数与时间限制。

| 范围 | 覆盖项 |
|---|---|
| 初始化 | Bank2 32 MiB / Bank1 16 MiB、CL2/CL3、命令顺序、8 次刷新、模式值、刷新计数 |
| 失败恢复 | 每一步 HAL_ERROR/HAL_BUSY/HAL_TIMEOUT、失败后不可访问、保留 PRECHARGED 后重试 |
| 停用与恢复 | 空实例、重复停用、保留 HAL/地址信息、停用后拒绝读写和自检、重新初始化 |
| 调用上下文 | ISR、PRIMASK、BASEPRI、FAULTMASK 被拒绝，且不发命令、不进入延时 |
| 错误参数 | 空实例/句柄、无效刷新周期、HAL 状态、总线宽度、ReadBurst、零时钟、刷新计数溢出 |
| 读写边界 | 空缓冲区、零长度、非对齐、整数溢出、容量尾部、与 SDRAM 重叠的缓冲区 |
| 数据正确性 | 写/读/填充、跨 16 MiB 边界、内存尾部、子区域前后哨兵保持不变 |
| 自检 | 参数错误不遗留旧错误记录、低/高地址模式、walking 1/0、数据位和地址别名故障注入 |
| 自检状态 | 数据不匹配自动停用；取消和参数错误保留 ready；带回调仍能检测地址别名 |
| 进度与取消 | 起始零进度、单调工作量、4096 字节最大通知间隔、最小范围和尾块、26 个通知点逐个取消、取消不越界 |
| 编译优化 | `-O0`、`-O2`、`-Os`，`-Wall -Wextra -Werror` |

这些测试验证软件行为，不模拟 FMC 电气时序或 SDRAM 刷新电路。

1.1.0 已在 GCC 12.3.1、Unicorn 2.1.4、pyelftools 0.32 下通过上述测试。
另将组件复制到临时目录，通过 `--include` 显式提供外部 HAL/CMSIS 头文件，
在不同工作目录下重新通过全部三个优化等级，验证测试不绑定原组件路径。
运行器参数与固定依赖见 [tests/README.md](../tests/README.md)。

## 工程构建

- Debug：默认日志与启动自检。
- Release：默认日志与启动自检。
- 独立 SoftwareOptions 构建：日志关闭、启动自检关闭，验证条件编译路径。
- 同一独立目录还检查日志关闭/自检开启、日志开启/自检关闭的组合。

标准预设：`cmake --build --preset Debug`、`cmake --build --preset Release`。
关闭选项：`-DCONFIG_LOG_ENABLED=OFF -DCONFIG_SDRAM_TEST_ENABLED=OFF`。
选项测试使用独立目录，保留 Debug 默认启动自检，方便下一次上板。

1.1.0 已重新通过 Debug、Release 构建，以及无日志/RTT 头文件依赖的最小示例严格语法检查。
日志/自检开关组合为此前软件基线的验证记录。
